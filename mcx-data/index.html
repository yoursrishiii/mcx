    Normalization logic —   per_gram = contract_price / grams_in_quote_unit  →  adjusted = per_gram × (999 / purity)  →  spread_bps = (adjusted / reference_adjusted − 1) × 10,000
    Every contract is re-based to one common basis: ₹ per gram of 999-purity gold. GOLDM quotes 995-purity metal, so it is scaled by 999/995 = 1.00402; the 999 contracts are already on the reference basis (factor 1.00000). Prices are quoted per 10 g for GOLDM and GOLDTEN, per 8 g for GOLDGUINEA and per 1 g for GOLDPETAL — GOLDM has a 100 g lot but is still quoted per 10 g. Spreads are relative to the reference contract selected below.

        Security — what this demo actually does

        This page is honest about its own limits. Here is exactly what is and is not protected.

        Transport. When hosted on GitHub Pages (or any HTTPS host), all traffic between your browser and the server is encrypted in transit with TLS/HTTPS. The page also ships a Content-Security-Policy that restricts what can load and execute.

        Passwords. Your password is never stored, and never leaves the browser. It is put through PBKDF2 (SHA-256, 210,000 iterations, a fresh 16-byte random salt per account) and only the resulting derived hash is kept in localStorage. The plain-text password is discarded as soon as your session key is derived.

        Stored data. Session and profile data written to browser storage is encrypted client-side with AES-GCM 256 using a key derived from your password. A new random IV is generated for every write. Reading that data requires the same unlocked browser session.

        Session lifetime. The dashboard signs you out automatically after 15 minutes of inactivity. With “Remember me”, the session key is persisted in this browser so a reload keeps you signed in — that makes the device, not just the password, part of the trust boundary.

        XSS handling. Every value you type is inserted into the page as text, never as markup, so a script tag inside a name field is displayed as characters rather than executed.

        What this is not. There is no backend. This is a front-end demonstration with demo authentication stored locally — it is not end-to-end encrypted, not bank-grade, not audited, and not a substitute for a real identity or account system. Anyone with access to this unlocked device and its browser storage could read or modify what is stored there. Do not enter a password you use anywhere else.
